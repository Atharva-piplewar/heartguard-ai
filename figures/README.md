# Model Evaluation Figures Directory

This directory contains publication-ready figures generated from the evaluation pipeline on the held-out test set:

- `model_comparison_bar.png`: Multi-metric comparison bar chart comparing Accuracy, Recall, Specificity, F1-Score, and ROC-AUC across all five models.
- `confusion_matrices.png`: Confusion matrices for each classifier showing True Negatives, False Positives, False Negatives, and True Positives.
- `roc_curves.png`: Receiver Operating Characteristic curves with Area Under Curve (AUC) values and baseline chance line.
- `pr_curves.png`: Precision-Recall curves illustrating trade-offs for clinical screening.
- `feature_importance.png`: Top-10 clinical feature importances for tree-based ensemble models (Random Forest and XGBoost).
